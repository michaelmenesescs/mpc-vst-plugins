# BreakSlicer

A tempo-synced break slicer for MPC OS (an audio effect: put it on a track or a return that plays a break). It records
what comes in, cuts it into slices on the bar grid and, slice by slice, plays it live or swaps in an earlier slice,
reversed, rolled, pitched, panned or effected, each by its own chance. With SLICE off the audio passes through unchanged.

| Control | What it does |
|---|---|
| SLICE | on / off (switching crossfades, no click) |
| SIZE | slice length: 1/4, 1/8, 1/16 or 1/32 of a bar (4/4) |
| GATE | how much of each slice sounds: lower = stutter |
| MIX | dry / wet |
| SHUFFLE | chance a slice is replaced by one of the previous bar's slices (halved on the downbeat) |
| REVERSE | chance a slice plays backwards |
| ROLL | chance a slice repeats its first half, third or quarter |
| PITCH | chance a slice is pitched -12, -5, +5 or +12 semitones |
| PAN | chance a slice is panned to a random place |
| FX | chance of an effect on the slice: bit crush, low-pass sweep or tape stop |

The Force's eight Q-Links follow the panel's two rows (GATE SHUFFLE REVERSE ROLL, MIX PITCH PAN FX); bank 2 = SIZE, SLICE.

How it keeps time: the wrapper hands the engine the host's song position every block (`"HAS_SONGPOS": 1`,
`wrapper/engine.h` `songpos()`), so slices land on the bar grid, survive loops and locates, and line up with every
other track. While the transport is stopped it keeps slicing at the last tempo. Slice boundaries crossfade over 2 ms.
Written for this repo; the idea follows audio slicers such as Audio Blast's BreadSlicer (closed source, no code from it).

Build, test and package (from the repo root):

    tools/build_port.sh ports/breakslicer/vst/vst.json
    tools/test_port.sh ports/breakslicer/vst/vst.json
    python3 tools/release.py --so ports/breakslicer/vst/build/breakslicer.so \
        --skin "ports/breakslicer/vst/build/skin/Citizen Science - VST - BreakSlicer" \
        --entry ports/breakslicer/vst/build/pluginlist-entry.xml --version 1.0.0 -o ports/breakslicer/vst/dist

Engine tests (from this folder; ASan / UBSan): `cc -std=gnu11 -fsanitize=address,undefined -DBREAKSLICER_TEST
-I../../wrapper -Isrc -o /tmp/bs_sim test/sim.c src/engine.c -lm && /tmp/bs_sim`. They check: SLICE off is bit-exact;
straight slices equal the input; one slice per grid step over 4 bars and over 50 loops of 3 beats at 97 BPM; REVERSE
plays the previous slice backwards sample for sample; GATE silences the rest of each slice; everything at 100% stays
bounded; free-running while stopped; state round trip.

The skin (layout.conf, panel_0.svg, hw_*.svg, skin.css) is generated by `ports/force-pack` (`m_misc.py` `pbreak`): an
invented desktop unit, cream face in a walnut case.
