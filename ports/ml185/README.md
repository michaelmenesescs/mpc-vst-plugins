# ML-185

An 8-stage step sequencer plugin in the style of the classic M185 / Metropolis stage sequencer. Each stage has a pitch
(scale degree), 1-8 pulses, a gate mode (Off, Single, Multi = ratchet on every pulse, Hold), slide and accent.
Global settings: length, direction (Forward, Reverse, Pendulum, Random), rate (1/32 to 1/4 with triplets), swing,
gate length, scale (11), root, octave, MIDI channel, velocity, accent velocity and a Randomize button. It follows
the host tempo and transport and restarts from stage 1 on play.

MPC ignores a VST's MIDI output, so the plugin opens its own ALSA sequencer port ("ML-185 <n>", loaded with
`dlopen("libasound.so.2")`): put ML-185 on a track, then pick "ML-185 1" as another track's MIDI input (enable it
in Preferences > MIDI if it is not listed). Its screen shows that port name on the KEY / MIDI tab.

Build and package (from the repo root):

    tools/build_port.sh ports/ml185/vst/vst.json
    python3 ports/ml185/vst/force_qlinks.py "ports/ml185/vst/build/skin/Citizen Science - VST - ML-185"
    tools/test_port.sh ports/ml185/vst/vst.json
    python3 tools/release.py --so ports/ml185/vst/build/ml185.so \
        --skin "ports/ml185/vst/build/skin/Citizen Science - VST - ML-185" \
        --entry ports/ml185/vst/build/pluginlist-entry.xml --version 1.0.0 -o ports/ml185/vst/dist

`force_qlinks.py` rewrites the skin's Program Mode Q-Links for the Force's row of 8 knobs (knobs 1-8 = Pitch 1-8,
bank 2 = Pulses 1-8). The skin (layout.conf, skin.css, panel_*.svg) is generated by `ports/force-pack/hwskin.py`.

Offline simulator (from this folder): `cc -DML185_TEST -I../../wrapper -Isrc -o /tmp/sim test/sim.c src/engine.c -lm -ldl &&
/tmp/sim [key value ...]` prints the notes it would send over two bars at 120 BPM.
Diagnostic build: add `-DWRAP_TRACE=1` to `build.cflags` (and `"WRAP_TRACE": 1` to `defines`) to log every
setParameter / changed getParameter to `/tmp/ml185.log` on the device.

Status (2026-10-08): installed and registered on a Force (MPC OS 3.x); plays, sends MIDI to another track, Q-Links
work in Screen mode. Track Q-Link mode sends nothing to the plugin (no setParameter arrives; see docs/NOTES.md).
